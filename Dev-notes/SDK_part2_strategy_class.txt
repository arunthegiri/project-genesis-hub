KAIROS CLASS (ananke/kairos.py)
================================================================================

This is the main class the user interacts with in Jupyter.
It takes a DataFrame, accepts entry/exit logic, runs the backtest bar by bar,
and can export results to the dashboard.

--------------------------------------------------------------------------------
CONSTRUCTOR
--------------------------------------------------------------------------------

    Kairos(df, name=None)

    Parameters:
        df      pandas DataFrame with columns: time, open, high, low, close, volume
                time can be either the index OR a column — handle both cases.
                If time is a column, set it as the index internally.
                Sort by time ascending to ensure correct bar order.
        name    optional string name for the strategy.
                If not provided, default to 'kairos_{timestamp}'

    Internal state to initialize:
        self.df             the cleaned DataFrame with time as index
        self.name           strategy name
        self._entry_long    None (will be set by enter_long)
        self._entry_short   None (will be set by enter_short)
        self._exit_cond     None (will be set by exit_trade)
        self._stop_loss     None
        self._take_profit   None
        self._quantity      1.0
        self._results       None (set after run())
        self._trades        []

METHODS

    enter_long(condition)
        """
        Define the condition to enter a long (buy) position.

        Parameters
        ----------
        condition : pd.Series of bool
            A boolean Series aligned to df.index. When True at bar N,
            the strategy will enter a long position at the OPEN of bar N+1.
            This simulates realistic execution — you cannot trade on the
            close of the same bar that generated the signal.

        Example
        -------
        >>> from ananke.indicators import rsi
        >>> rsi_vals = rsi(df['close'], 14)
        >>> s.enter_long(condition=rsi_vals < 30)
        """
        Store condition as self._entry_long.
        Validate it is a boolean Series aligned to df.index.
        Raise ValueError with clear message if not.

    enter_short(condition)
        """
        Define the condition to enter a short (sell) position.

        Parameters
        ----------
        condition : pd.Series of bool
            A boolean Series aligned to df.index. When True at bar N,
            the strategy will enter a short position at the OPEN of bar N+1.

        Example
        -------
        >>> rsi_vals = rsi(df['close'], 14)
        >>> s.enter_short(condition=rsi_vals > 70)
        """
        Store condition as self._entry_short.

    exit_trade(condition=None, stop_loss=None, take_profit=None)
        """
        Define the conditions to exit an open trade.

        At least one of condition, stop_loss, or take_profit must be provided.
        All three can be combined — whichever triggers first closes the trade.

        Parameters
        ----------
        condition : pd.Series of bool, optional
            Exit when this condition is True. Evaluated at each bar.
        stop_loss : float, optional
            Exit if the trade moves against you by this percentage.
            For long: exit if close < entry_price * (1 - stop_loss)
            For short: exit if close > entry_price * (1 + stop_loss)
            Example: 0.02 = exit if trade loses 2%
        take_profit : float, optional
            Exit if the trade moves in your favor by this percentage.
            For long: exit if close > entry_price * (1 + take_profit)
            For short: exit if close < entry_price * (1 - take_profit)
            Example: 0.05 = exit if trade gains 5%

        Example
        -------
        >>> s.exit_trade(
        ...     condition=rsi_vals > 65,
        ...     stop_loss=0.02,
        ...     take_profit=0.05
        ... )
        """
        Store all three as self._exit_cond, self._stop_loss, self._take_profit.
        Raise ValueError if none of the three are provided.

    set_quantity(qty)
        """
        Set the number of shares or contracts per trade.

        Parameters
        ----------
        qty : float
            Number of shares/contracts. Default is 1.0.
            Must be greater than 0.

        Example
        -------
        >>> s.set_quantity(10)  # trade 10 shares at a time
        """
        Store as self._quantity.
        Raise ValueError if qty <= 0.

    run()
        """
        Execute the backtest bar by bar through the DataFrame.

        Returns
        -------
        Results
            A Results object containing all trade records and performance
            statistics. Also stored internally as self._results.

        Raises
        ------
        ValueError
            If no entry condition has been set before calling run().

        Example
        -------
        >>> results = s.run()
        >>> results  # displays summary table in Jupyter
        """

        BACKTEST LOGIC — implement exactly as follows:

        1. Validate that at least one entry condition is set.
           Raise ValueError if neither _entry_long nor _entry_short is set.

        2. Initialize:
            trades = []
            open_trade = None
            equity = []  # track cumulative pnl at each bar

        3. Iterate bar by bar using enumerate(df.itertuples()):
            current_bar = row at index i
            next_bar = row at index i+1 (if exists)

            A. If there is an open trade, check exit conditions:

               Check stop loss:
                   long:  if current_bar.close < open_trade.entry_price * (1 - stop_loss)
                   short: if current_bar.close > open_trade.entry_price * (1 + stop_loss)
                   → close trade at current_bar.close, record trade, set open_trade = None

               Check take profit:
                   long:  if current_bar.close > open_trade.entry_price * (1 + take_profit)
                   short: if current_bar.close < open_trade.entry_price * (1 - take_profit)
                   → close trade at current_bar.close, record trade, set open_trade = None

               Check exit condition:
                   if _exit_cond is not None and _exit_cond[i] is True
                   → close trade at current_bar.close, record trade, set open_trade = None

               If last bar and trade still open:
                   → close trade at current_bar.close

            B. If there is NO open trade and there is a next bar:
               Check entry conditions:
                   if _entry_long[i] is True → create long Trade with
                       entry_time = next_bar.Index
                       entry_price = next_bar.open
                       quantity = self._quantity
                       stop_loss = self._stop_loss
                       take_profit = self._take_profit
                       set open_trade = new Trade

                   elif _entry_short[i] is True → create short Trade with
                       same fields but direction='short'

               Do NOT enter a new trade if one is already open.
               Do NOT enter on the last bar (no next bar to execute on).

            C. Track equity:
               cumulative_pnl = sum of pnl from all closed trades so far
               equity.append((current_bar.Index, cumulative_pnl))

        4. After loop ends:
           Create and return Results(trades=trades, equity=equity, df=self.df)
           Store as self._results

    export(name=None)
        """
        Export the strategy definition and backtest results to the dashboard.

        Sends a POST request to http://localhost:8080/api/strategies with the
        strategy definition and backtest results. After export, the strategy
        will appear in the dashboard dropdown.

        Parameters
        ----------
        name : str, optional
            Override the strategy name. If not provided, uses the name
            set in the constructor.

        Returns
        -------
        dict
            The server response containing the saved strategy id and name.

        Example
        -------
        >>> s.export('rsi_mean_reversion')
        Kairos 'rsi_mean_reversion' exported successfully ✓
        """
        If name is provided, update self.name.
        If self._results is None, raise RuntimeError telling user to call run() first.
        Build payload:
        {
            "name": self.name,
            "definition": {
                "has_long_entry": self._entry_long is not None,
                "has_short_entry": self._entry_short is not None,
                "stop_loss": self._stop_loss,
                "take_profit": self._take_profit,
                "quantity": self._quantity
            },
            "results": self._results.to_dict(),
            "symbol": df['symbol'].iloc[0] if 'symbol' in df.columns else None,
            "from_ts": str(df.index[0]),
            "to_ts": str(df.index[-1]),
            "interval": "1Min"
        }
        Call client.post_strategy(payload).
        Print: "Kairos '{name}' exported successfully ✓"
        Return server response.

    plot()
        """
        Plot the backtest results as an interactive chart in Jupyter.

        Generates two subplots:
        1. Price chart with entry/exit markers overlaid
        2. Equity curve showing cumulative PnL over time

        Entry markers:
            Long entries:  green upward triangle (^) at entry price
            Short entries: red downward triangle (v) at entry price

        Exit markers:
            Winning trades: green circle (o) at exit price
            Losing trades:  red circle (o) at exit price

        Lines connecting entry to exit are drawn for each trade,
        colored green for wins and red for losses.

        Example
        -------
        >>> s.plot()
        """
        Use matplotlib with two subplots stacked vertically.
        Top plot (70% height): close price line + trade markers
        Bottom plot (30% height): equity curve
        Use plt.tight_layout() for clean spacing.
        Add title with strategy name, win rate, and total return.
