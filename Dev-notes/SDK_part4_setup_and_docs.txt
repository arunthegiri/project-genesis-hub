# Ananke SDK

Python SDK for the Ananke Quant Trading Platform. Define, backtest, and export
trading strategies from Jupyter notebooks to the Ananke dashboard.

## Installation

    pip install -e /path/to/ananke-sdk/

## Quick Start

    from ananke import Kairos
    from ananke.indicators import rsi, sma

    # df is your OHLCV DataFrame already loaded from TimescaleDB
    s = Kairos(df, name='my_strategy')

    # Define entry conditions
    rsi_vals = rsi(df['close'], period=14)
    s.enter_long(condition=rsi_vals < 30)
    s.enter_short(condition=rsi_vals > 70)

    # Define exit conditions
    s.exit_trade(stop_loss=0.02, take_profit=0.05)

    # Run the backtest
    results = s.run()
    results  # displays summary table

    # Visualize
    s.plot()

    # Export to dashboard
    s.export()

## Kairos Examples

Include 3 complete working examples:

### Example 1: RSI Mean Reversion
    from ananke import Kairos
    from ananke.indicators import rsi, ema

    s = Kairos(df, name='rsi_mean_reversion')
    rsi_vals = rsi(df['close'], period=14)
    fast_ema = ema(df['close'], period=9)
    slow_ema = ema(df['close'], period=21)
    s.enter_long(condition=(rsi_vals < 30) & (fast_ema > slow_ema))
    s.enter_short(condition=(rsi_vals > 70) & (fast_ema < slow_ema))
    s.exit_trade(stop_loss=0.02, take_profit=0.05)
    results = s.run()
    s.plot()
    s.export()

### Example 2: Moving Average Crossover
    from ananke import Kairos
    from ananke.indicators import sma

    s = Kairos(df, name='ma_crossover')
    fast = sma(df['close'], 10)
    slow = sma(df['close'], 50)
    s.enter_long(condition=(fast > slow) & (fast.shift(1) <= slow.shift(1)))
    s.enter_short(condition=(fast < slow) & (fast.shift(1) >= slow.shift(1)))
    s.exit_trade(stop_loss=0.03, take_profit=0.06)
    results = s.run()
    s.export('ma_crossover')

### Example 3: Bollinger Band Squeeze
    from ananke import Kairos
    from ananke.indicators import bollinger, rsi

    s = Kairos(df, name='bollinger_rsi')
    bands = bollinger(df['close'], period=20, std=2)
    rsi_vals = rsi(df['close'], period=14)
    s.enter_long(
        condition=(df['close'] <= bands['lower']) & (rsi_vals < 35)
    )
    s.exit_trade(
        condition=(df['close'] >= bands['upper']) | (rsi_vals > 65),
        stop_loss=0.02
    )
    results = s.run()
    results.summary()
    s.plot()
    s.export()

## Performance Notes

- All indicators are computed using pandas vectorized operations — fast
  even on large DataFrames
- The backtest runs bar by bar in Python — for DataFrames over 100,000 rows
  consider using a date range filter to reduce data size
- Entry is always executed at the OPEN of the next bar after signal fires
  for realistic simulation
