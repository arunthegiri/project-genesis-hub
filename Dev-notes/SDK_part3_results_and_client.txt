RESULTS CLASS (ananke/results.py)
================================================================================

Returned by Kairos.run(). Displays a clean summary table automatically
when it is the last expression in a Jupyter cell.

--------------------------------------------------------------------------------
CONSTRUCTOR
--------------------------------------------------------------------------------

    Results(trades, equity, df)

    Parameters:
        trades  list of Trade objects from the backtest
        equity  list of (datetime, float) tuples — cumulative pnl at each bar
        df      the original DataFrame used in the backtest

    On construction, immediately calculate all statistics:

    total_trades        len(trades)

    winning_trades      count of trades where win == True

    losing_trades       count of trades where win == False

    win_rate            (winning_trades / total_trades) * 100
                        Return 0.0 if total_trades == 0

    total_pnl           sum of all trade.pnl values
                        Round to 4 decimal places

    total_pnl_pct       sum of all trade.pnl_pct values
                        This is cumulative return, not average
                        Round to 4 decimal places

    avg_win             mean pnl of all winning trades
                        Return 0.0 if no winning trades

    avg_loss            mean pnl of all losing trades (will be negative)
                        Return 0.0 if no losing trades

    largest_win         max pnl across all trades
                        Return 0.0 if no trades

    largest_loss        min pnl across all trades (most negative)
                        Return 0.0 if no trades

    profit_factor       abs(sum of winning pnl) / abs(sum of losing pnl)
                        Return 0.0 if no losing trades
                        Return float('inf') if no losing trades but wins exist

    max_drawdown        Maximum peak-to-trough drop in the equity curve
                        as a percentage of the peak value.
                        Algorithm:
                            peak = 0
                            max_dd = 0
                            for (time, equity_value) in equity:
                                if equity_value > peak:
                                    peak = equity_value
                                drawdown = (peak - equity_value) / peak * 100
                                            if peak > 0 else 0
                                if drawdown > max_dd:
                                    max_dd = drawdown
                        Return as positive percentage e.g. 5.23

    sharpe_ratio        Annualized Sharpe ratio assuming risk-free rate of 0.
                        Use per-trade returns (trade.pnl_pct / 100).
                        sharpe = mean(returns) / std(returns) * sqrt(252)
                        Return 0.0 if fewer than 2 trades or std == 0

    avg_trade_duration  Average timedelta from entry_time to exit_time
                        across all closed trades.
                        Format as human readable string e.g. "2h 15m"
                        Return "N/A" if no trades

        ┌─────────────────────────────────────────┐
        │         BACKTEST RESULTS SUMMARY         │
        ├──────────────────────┬──────────────────┤
        │ Total Trades         │ 42               │
        │ Winning Trades       │ 28               │
        │ Losing Trades        │ 14               │
        │ Win Rate             │ 66.67%           │
        │ Total PnL            │ $284.50          │
        │ Total Return         │ 12.45%           │
        │ Avg Win              │ $18.32           │
        │ Avg Loss             │ -$8.14           │
        │ Largest Win          │ $52.10           │
        │ Largest Loss         │ -$21.30          │

    to_dict()
        """
        Serialize all results to a JSON-compatible dictionary.

        Used by Kairos.export() to send results to the backend.

        Returns
        -------
        dict
            Contains all statistics and a 'trades' key with list of
            trade dictionaries from Trade.to_dict().

        Example
        -------
        >>> results.to_dict()
        {
            "total_trades": 42,
            "winning_trades": 28,
            "win_rate": 66.67,
            "total_pnl": 284.50,
            ...
            "trades": [
                {"trade_id": "...", "direction": "long", ...},
                ...
            ],
            "equity_curve": [
                {"time": "2026-05-12T09:30:00", "cumulative_pnl": 0.0},
                {"time": "2026-05-12T09:31:00", "cumulative_pnl": 2.50},
                ...
            ]
        }
        """

    __repr__()
        Calls self.summary() and returns empty string so Jupyter displays
        the table when Results is the last expression in a cell.

    __str__()
        Same as __repr__().

HTTP CLIENT (ananke/client.py)
================================================================================

Handles all HTTP communication with the Java Spring Boot backend.
Keep this simple and focused — one responsibility only.

--------------------------------------------------------------------------------
CONFIGURATION
--------------------------------------------------------------------------------

    BASE_URL = os.environ.get("ANANKE_API_URL", "http://localhost:8080")

    The user can override the backend URL by setting the environment variable:
        export ANANKE_API_URL=http://my-server:8080

FUNCTIONS
--------------------------------------------------------------------------------

    post_strategy(payload: dict) -> dict
        """
        Send a strategy definition and backtest results to the dashboard backend.

        Makes a POST request to {BASE_URL}/api/strategies with the payload
        serialized as JSON. Handles connection errors gracefully with
        clear error messages.

        Parameters
        ----------
        payload : dict
            The strategy definition and results to send. Must include
            at minimum: 'name', 'definition', 'results'.

        Returns
        -------
        dict
            The parsed JSON response from the server.

        Raises
        ------
        ConnectionError
            If the backend is not reachable. Includes a helpful message
            telling the user to make sure Docker is running.
        ValueError
            If the server returns a non-200 status code. Includes the
            status code and server error message.

        Example
        -------
        >>> from ananke.client import post_strategy
        >>> response = post_strategy({"name": "my_strategy", ...})
        >>> print(response)
        {"id": 1, "name": "my_strategy", "created_at": "..."}
        """
        Implementation:
            try:
                response = requests.post(
                    f"{BASE_URL}/api/strategies",
                    json=payload,
                    headers={"Content-Type": "application/json"},
                    timeout=10
                )
                if response.status_code not in (200, 201):
                    raise ValueError(
                        f"Backend returned {response.status_code}: {response.text}"
                    )
                return response.json()
            except requests.exceptions.ConnectionError:
                raise ConnectionError(
                    f"Cannot connect to Ananke backend at {BASE_URL}. "
                    "Make sure Docker is running: docker-compose up -d"
                )

    get_strategies() -> list

        Fetch all saved strategies from the backend.

        Returns
        -------
        list of dict

        Example

        >>> strategies = get_strategies()
        >>> for s in strategies:
        ...     print(s['name'])
        """

    from ananke import Kairos
    from ananke.indicators import rsi

    s = Kairos(df, name='test_rsi')
    rsi_vals = rsi(df['close'], 14)
    s.enter_long(condition=rsi_vals < 30)
    s.exit_trade(stop_loss=0.02, take_profit=0.05)

    results = s.run()

    results.to_dict()    # should return a clean dictionary
