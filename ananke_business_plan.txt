------------------------------------------------------------
1. WHAT ANANKE IS
------------------------------------------------------------

Ananke is a full-stack algorithmic trading development platform
that lets quantitative developers build, test, and deploy
production-grade trading strategies without managing low-level
infrastructure.

The platform consists of:
- Java Spring Boot backend — data ingestion from Alpaca Markets,
  stored in TimescaleDB, REST API for price history and backfill
- React frontend — candlestick charts, technical indicators,
  strategy monitoring dashboard
- Python SDK (Kairos) — pip-installable library for Jupyter
  notebooks, supporting indicators, backtesting, and model export
- C++ execution engine — low-latency order execution, ONNX model
  inference, live trading against broker APIs
- ML pipeline — ensemble model training framework (FirstRRC is
  the first production model built on it)

Current status: ML pipeline ~70% complete (Batches 1-3 done,
Batches 4-6 in progress). C++ engine in design phase.

------------------------------------------------------------
2. THE MARKET
------------------------------------------------------------

Target users (V1):
- Quantitative developers and applied math / CS students who
  want to build real trading systems without starting from scratch
- Researchers who need a clean Python-to-production pipeline
- Small prop trading desks that lack infrastructure engineering

The gap Ananke fills: existing platforms (QuantConnect, Zipline,
Backtrader) are either cloud-locked, Python-only with no
production path, or require significant DevOps to self-host.
Ananke owns the full stack from data ingestion to C++ execution,
with a clean SDK layer in between.

4. INCORPORATION — DO THIS BEFORE NVIDIA STARTS
------------------------------------------------------------

Timeline: incorporate within the next 6 weeks, before the
NVIDIA internship begins.

Why before NVIDIA:
  NVIDIA's IP agreement requires disclosure of outside projects.
  Having Ananke incorporated as a separate legal entity BEFORE
  signing that agreement provides cleaner protection of the work
  already built. Consult a lawyer for one hour before signing
  the NVIDIA offer letter — not after.

Entity type: Delaware C-Corp
  Rationale: Required for most startup grants, YC, and
  institutional investment. Easier to issue equity to future
  co-founders or advisors. Converting from LLC to C-Corp later
  is costly and annoying — do it right the first time.

How to incorporate: Stripe Atlas ($500)
  Handles filing, EIN, registered agent (first year), and
  Stripe account setup. Takes about one week.

Steps in order:
  1. Secure domain (see Section 5) — do this first
  2. Incorporate via Stripe Atlas using the domain email
  3. Open Mercury business bank account (free, startup-friendly)
  4. Set up AWS under the business account (separate from
     personal AWS — new account, new free tier, clean billing)
  5. Set a $20/month billing alert on AWS immediately
